How to Use

1. Upload — Either drag and drop your text file into the shaded area or click on the drop area block and select your file. The expected format is as follows:
timestamp, baseline, sample, temperature_C, voltage_V, current_mA

2. Parameters — The default flux equation parameters are a1=0.94, a2=3.4 (based on Estapa et al). If necessary they can be changed using the two entry boxes.

3. Compute Data — Click the Process Data button after uploading your text file. Processed data will be shown on the graphs.

4. Graph Display — Select the desired parameter to display on the graph by clicking the round button next to its name.

5. Export Results — Save the processed table data as a CSV file.
